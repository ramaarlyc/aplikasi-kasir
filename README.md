# Aplikasi Kasir Modern (Toko NK - Point of Sales)

Aplikasi Web Point of Sales (POS) / Kasir Ritel modern, responsif, dan praktis berbasis web HTML5, Tailwind CSS, dan JavaScript murni (SPA).

## Fitur Utama
- **Kasir (POS)**: Katalog produk ritel cepat, pencarian otomatis, shortcut keyboard (F2 & F4).
- **Scanner Barcode**: Dukungan barcode scanner hardware (USB/Bluetooth) & scan kamera langsung via `html5-qrcode`.
- **Manajemen Keranjang**: Multi-item, kuantiti cepat, diskon (persen / nominal), kalkulasi PPN 11%, dan pembulatan koin tunai.
- **Tahan Antrean (Hold Orders)**: Simpan antrean pelanggan sementara dan panggil kembali sewaktu-waktu.
- **Metode Pembayaran**: Tunai (kalkulasi kembalian otomatis & tombol cepat), QRIS digital, Debit/Kredit, dan Transfer Bank.
- **Cetak Struk & WhatsApp**: Struk format kasir thermal 80mm dan fitur kirim nota digital langsung ke nomor WhatsApp pembeli.
- **Inventaris & Stok Ritel**: Manajemen SKU/barcode ritel, harga modal, harga jual, penambahan stok instan (+10), dan deteksi stok kritis (<= 5).
- **Riwayat Penjualan & Dashboard Omset**: Rekap omset total, jumlah transaksi, unit terjual, cetak ulang struk, dan ekspor riwayat ke file CSV.
- **Offline / LocalStorage**: Data tersimpan aman di browser pengguna.
